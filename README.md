# Global AI Adoption in Education

## Project Overview

This project focuses on analyzing Global AI Adoption in Education using Tableau.
The project provides interactive dashboards and stories to understand AI adoption
patterns and generate meaningful insights from the dataset.

## Dataset

The dataset used for this project is:

- Global AI in Education (5).csv

## Tableau Dashboard

The Tableau Dashboard provides interactive visualizations and allows users to
analyze the key insights from the dataset.
